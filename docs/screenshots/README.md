## Replacing them

1. Capture at **1080 × 2400** (or any 9:20 device, then resize to that size).
2. Use demo data — no real project names, paths, tokens, hostnames or API keys.
3. Keep the same filenames; the README references them directly.
4. Prefer light theme for consistency with the other captures.

Nothing else needs to change: the README table is set to 220 px wide with the
9:20 aspect ratio, so replacement images drop in without layout shifts.
